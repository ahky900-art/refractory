# 내화물 마모 대시보드

설비별 탭으로 구성한 내화물(라이닝) 마모 대시보드예요. 생산 스케줄(부하, 가동일수, 정지·재가동, 대기시간)이 바뀌면 마모가 어떻게 달라지는지 볼 수 있어요.

| 탭 | 내용 | 데이터 성격 |
|---|---|---|
| 래들 | SINTEF/refractorywear 실제 모델을 조건과 대기시간을 바꿔 다시 돌린 결과 | 실제 모델 실행값(조건 사이는 보간) |
| 로타리 킬른 | 지름 약 4.2 m, 길이 60 m, 경사, 타이어 3곳, 5개 구역 | 형상은 자료 기반, 두께·수명·스케줄 민감도는 가정 |
| RFCC 재생기 | 에어그리드, 덴스 베드, 전이 콘, 희박상, 내부 사이클론, 상부 헤드 | 위와 같음 |
| 소각로 | 로타리 킬른(3구역) + 핫덕트 + 2차 연소실(2구역) | 위와 같음 |
| 가열로 | 워킹빔 가열로: 계단식 천장, 천장/노상 라이닝 구분 | 위와 같음 |
| 고로 | 2,100 m3급 내부 프로파일 | 위와 같음 |
| 2차 개질로 | 접시형 헤드, 촉매 지지 돔, 촉매층, 연소 영역, 상부 콘, 버너 넥 | 위와 같음 |
| 흡수탑 | FGD 흡수탑의 내식 라이닝 | 위와 같음 |
| 화력 보일러 | 순환유동층(CFB) 보일러 | 위와 같음 |

## 생산 스케줄 반영

### 래들 (실제 모델 기반)
- 래들 1기의 하루 히트 수(3~13.5)를 바꾸면 히트 사이 빈 래들 대기시간이 달라져요 (대기 = 24/하루 히트 수 - 1.5 h).
- 모델의 빈 래들 구간(기본 1 h)을 0.25~6 h로 바꿔 실제로 다시 돌렸어요. 대기가 길수록 벽이 식어 히트당 침식은 줄지만(0.25 h: 1.10%, 6 h: 0.88%) 강철 온도는 더 떨어지고, 같은 히트 수에 걸리는 일수는 늘어요.
- 시나리오: 정상, 수요 감소·회복(30~60번째 히트에서 대기 +3 h), 막판 증산(60번째 히트부터 대기 0.25 h), 들쭉날쭉(히트마다 번갈아). 침식은 히트마다 그때의 대기시간에 맞는 값을 누적해요.
- 래들에서 찬 벽의 열충격 박락은 이 모델이 계산하지 않아요.

### 다른 설비 (가정 기반)
- 입력: 기준 가동 부하(%), 월 가동일수, 월 정지·재가동 횟수, 시나리오(정상, 수요 감소, 계절 변동, 잦은 정지, 증산).
- 월 마모율 = (0.6/수명) x [(1-cs) x 부하^kL x 가동일/30 + cs x 정지횟수/기준정지횟수]
  - kL: 부하 지수(침식·고온 구역이 클수록 부하에 민감), cs: 정지(열충격)가 차지하는 비중. 구역별 값은 가정이에요.
  - 기준(부하 100%, 월 30일, 기준 정지 횟수)에서는 수명과 정확히 같아요.
- `EQS`의 `S0`(기준 정지 횟수), `kL`, `cs`를 실제 설비 자료로 바꿔 쓰세요.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages(Settings > Pages > main / root)로 배포하세요.
차트와 3D 라이브러리를 인터넷(cdnjs)에서 불러와요.

## 주의

- 래들 외 탭의 두께, 수명, 스케줄 민감도는 실제 측정이나 모델 결과가 아니에요.
- 래들 보간 오차: 침식 프로필 평균 약 5%, 최대 약 11% (격자 밖 조건 검증). 대기시간 조합은 별도 검증을 하지 않았어요.
- 일반 미분탄 보일러는 대부분 수냉벽이라 내화물이 거의 없어서, 보일러 탭은 CFB 보일러로 그렸어요.
