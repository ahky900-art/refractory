# 내화물 마모 대시보드

설비별 탭으로 구성한 내화물(라이닝) 마모 대시보드예요. 생산 스케줄이 바뀌면 마모가 어떻게, 왜 달라지는지, 어느 구역·어느 위치가 먼저 닳는지, 그리고 정비 때 어디로 들어가는지까지 볼 수 있어요.

## 어떤 탭이 수식으로 계산하나

| 탭 | 계산 방식 | 근거 수준 |
|---|---|---|
| 래들 | SINTEF/refractorywear 실제 모델을 조건·대기시간을 바꿔 다시 돌린 결과(37행) | 실제 모델 |
| 로타리 킬른 | 온도 프로파일 x 아레니우스형 용해 x 코팅 + 마모 + 알칼리 | 수식(계수는 가정) |
| 화력 보일러(CFB) | 입자 침식 c(y) x (u x 경계효과 x 부하)^n, 사이클론 속도 감쇠·콘 집중 | 수식(계수는 가정) |
| RFCC 재생기 | 입자 침식(에어그리드 제트, 베드 표면 분출, 희박상 감쇠, 사이클론) | 수식(계수는 가정) |
| 가열로 | 노상: 용융 스케일(1177 °C) 침식, 천장: 연소 복사 아레니우스 | 수식(계수는 가정) |
| 고로 | 노상만 용선 응고 등온선(1150 °C) 평형 모델, 나머지 구역은 가정 | 일부 수식 |
| 소각로, 2차 개질로, 흡수탑 | 구역별 수명·분포를 가정 | 가정 |

수식 탭의 구역 수명은 입력이 아니라 계산 결과예요(보정 상수 K 하나만 맞춤). 각 탭의 "부위별 마모 수식과 가정값" 카드에서 수식과 모든 계수의 출처를 확인하세요.

## 철골 구조, M/H, 정비 진입

- 도면 표시 토글(철골·M/H 표시 / 끄기)로 철골(스커트, 지지 기둥, 링 거더, 버크스테이, 지지 피어, 플랫폼, 사다리)과 M/H·출입구를 겹쳐 볼 수 있어요. 번호 원을 누르면 표의 해당 행이 강조돼요(표의 행을 눌러도 도면에서 강조).
- "정비 진입 방법" 카드: M/H 번호별 위치·크기(예시)·용도, 정비 진입 순서, 보수 방법.
  - 킬른: 연소 후드 도어·공급 끝 스모크 챔버로 진입, 냉각·쉘 온도·가스 측정·밀폐공간 허가, 비계와 벽돌 쌓기 기계
  - RFCC: 기름 차단 후 36~48시간에 첫 진입(사례), M/H 열기 전 촉매 폭연 주의, 콘 비계, 상부 절단 후 헤드와 사이클론 일괄 인양
  - 고로: 휴풍, 살라맨더 출선, 급냉, 질소 퍼지, 영구 개구부 개방, 쉘을 계획 위치에서 절단해 진입
  - 래들: 상부가 열려 있어 보수대에서 위로 해체·시공, 바닥 플러그·슬라이드 게이트는 아래에서 교체
- M/H의 위치와 크기는 예시예요. 실제 설비 도면과 절차서를 따르세요.

## 그 밖의 기능

- 구역 안 위치별 잔여 두께(8개 구간, 벽 A/B), 선택한 구역의 잔여 두께 KPI(평균 포함), 점검 실측값 반영
- 스케줄: 기준 가동 부하, 월 가동일수, 월 정지·재가동, 시나리오. 래들은 하루 히트 수로 정해지는 빈 래들 대기시간(실제 모델 재실행)
- 메커니즘 설명 카드(침식, 화학·고온, 열충격, 기계)와 구역별 마모 속도 배율(부하 몫 / 정지 몫), 래들 인자별 영향 차트

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages(Settings > Pages > main / root)로 배포하세요.
차트와 3D 라이브러리를 인터넷(cdnjs)에서 불러와요.

## 주의

- 수식의 형태는 일반적인 마모 모델이지만 계수는 대부분 가정이에요. 실제 설비 두께 측정값으로 맞춰야 정량값이 돼요.
- 정비 진입 순서와 냉각 시간은 업체·현장 자료의 일반 범위이고 설비마다 달라요. 소각로, 가열로, 2차 개질로, 흡수탑, CFB는 일반 예시예요.
- 래들 보간 오차: 침식 프로필 평균 약 5%, 최대 약 11%. 대기시간 조합은 별도 검증을 하지 않았어요.
