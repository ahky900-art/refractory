# 가열로 생산시퀀스·MILP 정비 최적화

## 목적
가열로 4대의 정비 대상과 착수 시점을 생산 시퀀스 및 강종군별 수요 제약에 따라 최적화하는 브라우저 기반 MILP 프로토타입입니다.

## 대시보드 범위
현재 공개 대시보드는 가열로 MILP 기능만 제공합니다. 기존 래들·킬른·소각로 등 설비별 내화물 분석, 온톨로지 그래프, 일반 제철소 공정학습 및 범용 정비 체크리스트 탭은 화면에서 제외했습니다.

- 가열로 1·2호기: A강종군
- 가열로 3·4호기: B강종군
- 생산 시퀀스: 단계별 일수와 A/B 강종군 주간·야간 수요 입력
- 계획기간: 기본 28일, 56개 교대
- 정비기간: 기본 14일, 연속 28개 교대
- 최적화: 정비 대상 1대와 정비 시작 교대를 선택
- 제약: 강종군별 생산능력, 정비기간, RUL, 동시 정비 대수
- 출력: MILP 상태, 목적함수 값, 선정 근거, 강종군별 여유능력 검산, 생산·정비 Gantt

## 수학적 모델 개요
결정변수는 (x_{i,s}\in\{0,1\})이며, 가열로 (i)를 교대 (s)부터 정비하면 1입니다.

\[
\min Z=\sum_{i,s}\left(C_i+\alpha_i d_s-R_i\right)x_{i,s}
\]

\[
\sum_{i,s}x_{i,s}=1
\]

강종군 (g\in\{A,B\}), 교대 (t)에 대해 정비 중인 가열로의 능력을 차감한 잔여 능력이 생산 수요 이상이어야 합니다.

\[
\sum_{i\in g}Cap_i-
\sum_{i\in g}\sum_{s:\,s\le t<s+D}Cap_i x_{i,s}
\ge Demand_{g,t}
\]

RUL 및 동시 정비 제약도 함께 적용합니다. 실제 구현은 브라우저에서 GLPK.js를 불러와 이진 정수 최적화를 수행합니다.

## 실행
GitHub Pages 배포 주소에서 열거나 저장소의 `index.html`을 브라우저로 엽니다. GLPK.js는 CDN에서 로드되므로 최적화 실행 시 인터넷 연결이 필요합니다.

## 중요 한계
- 기본 입력값은 설명용 가정값이며 실제 제철소 운전 데이터가 아닙니다.
- 현재 모델은 사용자가 입력한 생산 시퀀스를 고정하고 정비 대상·시점을 최적화합니다. 생산 시퀀스의 순서나 제품 믹스 자체를 최적화하지는 않습니다.
- 위험회피 편익 (R_i), 정비비 (C_i), 지연비용 (α_i), RUL 및 가열로 능력은 실제 고장·정비·생산·재무 자료로 보정해야 합니다.
- 목적함수의 비용 항목은 동일한 금액 단위로 환산해야 합니다.
- 계산 결과는 의사결정 지원용이며 안전·품질 승인, 설비 검사, 제조사 승인 Dry-out 절차를 대체하지 않습니다.
