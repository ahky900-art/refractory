# 내화물 마모 대시보드

설비별 탭으로 구성한 내화물(라이닝) 마모 대시보드예요. 생산 스케줄(부하, 가동일수, 정지·재가동, 대기시간)이 바뀌면 마모가 어떻게, 왜 달라지는지 볼 수 있어요.

| 탭 | 내용 | 데이터 성격 |
|---|---|---|
| 래들 | SINTEF/refractorywear 실제 모델을 조건과 대기시간을 바꿔 다시 돌린 결과 | 실제 모델 실행값(조건 사이는 보간) |
| 로타리 킬른, RFCC 재생기, 소각로, 가열로, 고로, 2차 개질로, 흡수탑, 화력 보일러(CFB) | 형상은 공개 자료 기반 | 두께·수명·스케줄 민감도는 가정 |

## 스케줄이 내화물에 주는 부하 (메커니즘)

모든 탭에 "스케줄이 내화물에 주는 부하" 카드가 있어요. 스케줄 변수 → 물리적 변화 → 내화물 반응 → 손상 부위 순서로, 색 칩으로 구분해요.

- 침식(파랑): 입자·흐름이 벽을 깎아요. 속도가 오르면 마모가 크게 늘어요.
- 화학·고온(주황): 슬래그·알칼리·용강이 벽돌을 녹여요. 온도와 흐름이 빠를수록 빨라요.
- 열충격·열사이클(보라): 정지·재가동, 대기 후 재장입처럼 온도가 급변할 때 금이 가고 박락해요.
- 기계(회색): 장입물 충격, 쉘 변형, 열팽창 때 틈에 낀 분진이 미는 힘이에요.

래들 탭에는 "어떤 인자가 침식을 키우나" 차트가 있어요. 강철량, 출강 온도, 교반 가스, 전력, 대기시간을 하나씩만 현재 값으로 바꿨을 때 히트당 최대 침식이 기준 대비 몇 % 변하는지와, 전부 합친 값을 보여줘요. 수치는 실제 모델 재실행 결과예요.

다른 탭에는 "지금 스케줄의 마모 속도 배율(구역별)" 차트가 있어요. 배율을 부하·가동 시간 몫(파랑)과 정지·재가동 몫(보라)으로 나눠서, 구역마다 무엇이 마모를 키우는지 보여줘요.

## 스케줄 반영 방식

### 래들
- 래들 1기의 하루 히트 수를 바꾸면 히트 사이 빈 래들 대기시간이 달라져요 (대기 = 24/하루 히트 수 - 1.5 h). 모델의 빈 래들 구간(0.25~6 h)을 바꿔 실제로 다시 돌렸어요.
- 시나리오: 정상, 수요 감소·회복, 막판 증산, 들쭉날쭉. 히트마다 그때의 대기시간에 맞는 침식을 누적해요.
- 찬 벽의 열충격 박락은 이 모델이 계산하지 않아요.

### 다른 설비
- 입력: 기준 가동 부하(%), 월 가동일수, 월 정지·재가동 횟수, 시나리오(정상, 수요 감소, 계절 변동, 잦은 정지, 증산).
- 월 마모율 = (0.6/수명) x [(1-cs) x 부하^kL x 가동일/30 + cs x 정지횟수/기준정지횟수]
  - kL: 부하 지수, cs: 정지(열충격)가 차지하는 비중. 구역별 값은 가정이에요. 기준 조건에서는 수명과 같아요.
- `EQS`의 `S0`, `kL`, `cs`, 메커니즘 카드의 `ch`를 실제 설비 자료로 바꿔 쓰세요.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages(Settings > Pages > main / root)로 배포하세요.
차트와 3D 라이브러리를 인터넷(cdnjs)에서 불러와요.

## 주의

- 래들 외 탭의 두께, 수명, 스케줄 민감도, 메커니즘별 비중은 실제 측정이나 모델 결과가 아니에요.
- 래들 보간 오차: 침식 프로필 평균 약 5%, 최대 약 11% (격자 밖 조건 검증). 대기시간 조합은 별도 검증을 하지 않았어요.
- 일반 미분탄 보일러는 대부분 수냉벽이라 내화물이 거의 없어서, 보일러 탭은 CFB 보일러로 그렸어요.
