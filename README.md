# 내화물 마모 대시보드

설비별 탭으로 구성한 내화물(라이닝) 마모 대시보드예요. 생산 스케줄(부하, 가동일수, 정지·재가동, 대기시간)이 바뀌면 마모가 어떻게, 왜 달라지는지, 어느 구역·어느 위치가 먼저 닳는지 볼 수 있어요.

## 어떤 탭이 수식으로 계산하나

| 탭 | 계산 방식 | 근거 수준 |
|---|---|---|
| 래들 | SINTEF/refractorywear 실제 모델을 조건·대기시간을 바꿔 다시 돌린 결과(37행) | 실제 모델 |
| 로타리 킬른 | 온도 프로파일 x 아레니우스형 용해 x 코팅 + 마모 + 알칼리 | 수식(계수는 가정) |
| 화력 보일러(CFB) | 입자 침식 c(y) x (u x 경계효과 x 부하)^n, 사이클론 속도 감쇠·콘 집중 | 수식(계수는 가정) |
| RFCC 재생기 | 입자 침식(에어그리드 제트, 베드 표면 분출, 희박상 감쇠, 사이클론) | 수식(계수는 가정) |
| 가열로 | 노상: 용융 스케일(1177 °C) 침식, 천장: 연소 복사 아레니우스 | 수식(계수는 가정) |
| 고로 | 노상만 용선 응고 등온선(1150 °C) 평형 모델, 나머지 구역은 가정 | 일부 수식 |
| 소각로, 2차 개질로, 흡수탑 | 구역별 수명·분포를 가정 | 가정 |

수식 탭의 구역 수명은 입력이 아니라 계산 결과예요. 보정 상수 K 하나(가장 닳는 구역이 정해진 개월에 교체 기준에 닿도록)만 맞추고, 나머지 구역과 구역 안 위치별 차이는 수식에서 나와요. 각 탭의 "부위별 마모 수식과 가정값" 카드에서 수식과 모든 계수의 출처(문헌 일반값 / 가정)를 확인하세요.

## 주요 기능

- 구역 안 위치별 잔여 두께: 구역을 8개 구간으로 나눠 위치마다, 벽 A(위·왼쪽)와 벽 B(아래·오른쪽)마다 다르게 그려요.
- 스케줄: 기준 가동 부하, 월 가동일수, 월 정지·재가동, 시나리오(정상, 수요 감소, 계절 변동, 잦은 정지, 증산). 수식 탭은 부하가 수식 안으로 들어가고(속도·온도 변화), 정지는 열충격 항으로 더해져요.
- 메커니즘 설명 카드(침식, 화학·고온, 열충격, 기계)와 구역별 마모 속도 배율(부하 몫 / 정지 몫) 차트
- 점검 실측값 반영: `구역번호,가장 얇은 곳 잔여 mm`를 넣으면 그 구역은 실측에서 시작해 남은 기간을 다시 계산해요.
- 래들: 하루 히트 수로 정해지는 빈 래들 대기시간(실제 모델 재실행 결과), 인자별 영향 차트

## 월 마모율

월 마모율 = K x [(1 - cs) x φ(부하) x 가동일/30 + cs x φ(1) x 정지횟수/기준정지횟수]

φ는 설비별 수식, cs는 열충격 비중(가정)이에요. 고로 노상은 평형 접근식 dw/dt = (w평형 - w)/τ를 써요.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages(Settings > Pages > main / root)로 배포하세요.
차트와 3D 라이브러리를 인터넷(cdnjs)에서 불러와요.

## 주의

- 수식의 형태는 일반적인 마모 모델이지만 계수(침식 지수, 활성화 에너지, 농도·속도비, 온도 프로파일 등)는 대부분 가정이에요. 실제 설비 두께 측정값으로 계수를 맞춰야 정량값이 돼요.
- 래들 보간 오차: 침식 프로필 평균 약 5%, 최대 약 11%. 대기시간 조합은 별도 검증을 하지 않았어요.
- 일반 미분탄 보일러는 대부분 수냉벽이라 내화물이 거의 없어서, 보일러 탭은 CFB 보일러로 그렸어요.
