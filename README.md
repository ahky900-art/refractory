# 내화물 마모 대시보드

설비별 탭으로 구성한 내화물(라이닝) 마모 대시보드예요.

| 탭 | 내용 | 데이터 성격 |
|---|---|---|
| 래들 | SINTEF/refractorywear(MIT)를 공개 히트 7654321로 실제 실행한 결과. 2D 도면, 3D 단면, 행별 침식, 온도 | 실제 모델 실행값 |
| 로타리 킬른 | 지름 약 4.2 m, 길이 60 m, 경사, 타이어 3곳, 5개 구역 | 형상은 자료 기반, 두께·수명은 가정 |
| RFCC 재생기 | 에어그리드, 덴스 베드, 전이 콘, 희박상, 내부 사이클론, 상부 헤드 | 형상은 자료 기반, 두께·수명은 가정 |
| 소각로 | 로타리 킬른(3구역) + 핫덕트 + 2차 연소실(2구역) | 형상은 자료 기반, 두께·수명은 가정 |
| 가열로 | 워킹빔 가열로: 계단식 천장, 천장/노상 라이닝 구분, 5개 구역 | 형상은 자료 기반, 두께·수명은 가정 |
| 고로 | 2,100 m3급 내부 프로파일: 노상, 보시, 벨리, 샤프트, 노구 | 형상은 자료 기반, 두께·수명은 가정 |
| 2차 개질로 | 접시형 헤드, 촉매 지지 돔, 촉매층, 연소 영역, 상부 콘, 버너 넥 | 형상은 자료 기반, 두께·수명은 가정 |
| 흡수탑 | FGD 흡수탑: 반응 탱크, 입구 덕트, 스프레이, 데미스터, 출구 | 형상은 자료 기반, 두께·수명은 가정 |

## 도면 형상의 근거

- 고로: 2,100 m3급 고로 내부 치수(노상 지름 10.4 m·높이 4.35 m, 보시 3.4 m, 벨리 지름 11.55 m·2.2 m, 샤프트 13.95 m, 노구 지름 8.15 m, 보시각 약 80°, 샤프트각 약 83°)
- 킬른: L/D 약 13~17, 경사 3.5~4%, 타이어 3곳, 쉘 지름 대비 라이닝 비율
- RFCC 재생기: 지름 약 9~11 m, 덴스 베드 깊이 3~4.5 m, 전이 콘 20~40°, 사이클론은 상부에 매달림
- 가열로: 길이 약 42 m, 높이 3.4~4.0 m, 예열대 상부 공간 0.9 m / 가열·균열대 1.8 m / 하부 2.2 m
- 2차 개질로: 촉매 2.8 m, 촉매 39 m3에서 지름 약 4.2 m 역산, 단열 캐스터블 200 mm 포함 총 약 390 mm
- 소각로: 킬른 지름 1.2~3 m·길이 6~12 m, 2차 연소실 1100 °C·2초 이상
- 흡수탑: 500 MW급 약 37 m 높이·18 m 지름 자료를 축소한 비율, 입구 덕트는 옆면, 스프레이 다단, 2단 데미스터

도면은 모식도예요. 두께는 보이도록 확대했고(킬른·가열로는 높이도 확대), 실제 설비 도면이 아니에요.

## 실행

`index.html`을 브라우저로 열거나 GitHub Pages(Settings > Pages > main / root)로 배포하세요.
차트와 3D 라이브러리를 인터넷(cdnjs)에서 불러와요.

## 실제 설비 데이터로 바꾸기

`index.html` 스크립트의 `EQS` 객체에서 구역별 길이(L), 반지름(r), 라이닝 두께(w, ins, sh), 재질, 수명(life, 개월)을 바꾸면
도면과 차트가 따라 바뀌어요. 좌표가 필요한 구조(소각로)는 `g`(중심선 좌표)로 직접 지정해요.

## 주의

- 래들 외 탭의 두께, 수명, 마모는 실제 측정이나 모델 결과가 아니라 공개 자료의 일반 범위를 바탕으로 한 가정이에요.
- 마모는 구역별로 월 일정(선형)이라고 가정했고, 수명은 잔여 두께 40%에 닿는 시점에 맞췄어요.
- 흡수탑은 고온 내화물이 아니라 내식 라이닝이라, 마모는 부식·마모로 인한 라이닝 두께 감소로 해석하세요.
